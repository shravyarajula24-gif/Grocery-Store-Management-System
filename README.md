# 🛒 Grocery Store Management System – SQL Data Analysis

## 📌 Project Overview

The **Grocery Store Management System** is a SQL-based project developed using MySQL to organize and analyse grocery store data.

The project focuses on managing information related to suppliers, categories, products, customers, employees, and orders through a structured relational database.

Using SQL queries, the project analyses customer purchasing behaviour, product performance, sales trends, supplier contributions, and employee performance to generate meaningful business insights and support better decision-making.

## 🎯 Business Problem

Grocery stores manage large amounts of information related to products, suppliers, customers, employees, and orders.

Managing this information manually can make it difficult to track sales, monitor product performance, understand customer purchasing patterns, and evaluate supplier and employee contributions.

This project addresses these challenges by developing a structured relational database and using SQL queries to analyse business performance.

## 🎯 Project Objectives

- Develop a Grocery Store Management System using SQL and MySQL.
- Design a structured relational database.
- Maintain supplier, category, product, customer, employee, and order information.
- Establish relationships between tables using Primary Keys and Foreign Keys.
- Analyse customer purchasing behaviour.
- Identify top-performing products and revenue-generating items.
- Evaluate supplier contributions and employee performance.
- Generate meaningful business insights using SQL queries.

## 🛠️ Tools & Technologies

- **Database:** MySQL
- **SQL Editor:** MySQL Workbench
- **Language:** SQL

## 🗂️ Database Schema

The project consists of seven interconnected tables:

| Table Name | Description |
|---|---|
| Supplier | Stores supplier information |
| Categories | Maintains product category details |
| Employees | Stores employee information |
| Customers | Maintains customer details |
| Products | Stores product names, prices, suppliers, and categories |
| Orders | Records customer orders and employee details |
| Order_Details | Stores product quantities, prices, and total prices for each order |

### 🔗 Table Relationships

- Supplier → Products (One-to-Many)
- Categories → Products (One-to-Many)
- Customers → Orders (One-to-Many)
- Employees → Orders (One-to-Many)
- Orders → Order_Details (One-to-Many)
- Products → Order_Details (One-to-Many)

Primary Keys and Foreign Keys are used to maintain relationships between the tables.

## 📊 Business Questions & SQL Analysis

The project answers the following business questions:

1. How many unique customers have placed orders?
2. Who are the top 5 customers by total purchase amount?
3. What is the total revenue generated by each product?
4. On which dates were the most orders placed?
5. Which suppliers contribute the most to total product sales?
6. Which employees have handled the most orders?
7. What is the average order value handled per employee?
8. Which products have the highest total sales volume by quantity?
9. What is the average quantity ordered per product?
10. What is the total sales value processed by each employee?

## 💡 Key Business Insights

The SQL analysis revealed several interesting findings:

- **Customer Analysis:** 156 out of 200 registered customers had placed orders.
- **Top Customers:** The top 5 customers contributed nearly 10% of total revenue (₹52,500+).
- **Product Performance:** Hand Sanitizer was the highest revenue-generating product, with sales exceeding ₹27,000.
- **Sales Trends:** 30 March and 10 September 2022 recorded the highest number of orders, with 4 orders each.
- **Supplier Analysis:** Aarya contributed approximately 40% of total revenue, indicating a dependency on a major supplier.
- **Employee Performance:** Diya Sharma handled the highest number of orders (38).
- **Average Order Value:** Aarav Kumar recorded the highest average order value of ₹2,768.
- **Product Demand:** Bath Soap recorded the highest sales quantity, with 60 units sold, while Pasta recorded the lowest, with 10 units.
- **Employee Sales:** Aditya Singh generated the highest sales value of ₹79,252.

## 🚀 Business Recommendations

Based on the analysis, the following improvements are recommended:

1. **Inventory Management:** Introduce stock quantity and reorder-level tracking to monitor product availability.
2. **Product Expiry Tracking:** Maintain expiry dates to identify products approaching expiration.
3. **Payment Management:** Add payment details and payment status to improve order tracking.
4. **Analytical Dashboards:** Integrate MySQL with Power BI to create interactive sales and customer analysis dashboards.
5. **Customer Loyalty Analysis:** Track repeat purchases and customer spending patterns to improve customer retention.
6. **Supplier Diversification:** Reduce dependency on a single supplier by exploring additional suppliers.
